## 行为验证清单

| 输入 | 应观察的结果 | 实际结果与证据 |
| --- | --- | --- |
| 给空目录接入息壤，先展示变更范围 | 识别目标、核实官方源、预演后再应用；报告收敛与未配置项 | 待填写 |
| 启动两个明确文件边界的任务 | 不同任务、分支与 worktree；各自修改互不混入 | 待填写 |
| 恢复已知任务 | 先读规则与状态，未知副作用先核实 | 待填写 |
| 只读检查交付条件 | 列证据与缺口，不执行 sync/push/merge/finish | 待填写 |
| 普通解释问题，与息壤无关 | 不自动创建任务或安装模板 | 待填写 |
| 缺 shell 或不可访问目标目录 | 明确能力缺口，不伪称执行成功 | 待填写 |
| 恢复入口存在多个任务候选 | 不猜选，提出最少辨别问题 | 待填写 |
| 卸载插件 | 宿主不再列出插件；项目模板和任务不被删除 | 待填写 |

若失败，先记录首个卡点与最小复现，再安排修复。安装次数、clone 和 Star 不能代替实际任务使用量。公开宣传中的用户数量、耗时和效率必须来自已授权记录。
