# ADR 026：版本化能力包与所有权引擎

状态：Accepted；日期：2026-09-08；关联：US-ARCHPLAT-001~009。

息壤需要同时约束模型作业与生成真实项目架构，并维护项目定制。选择两个独立 manifest 的能力包和统一冻结计划引擎，保留旧执行路径作为兼容 API。技术选择按应用和存储建模；应用目录由项目映射。

不把技术选型写死进作业规则，不把整个模板重新复制到业务目录。生成后可编辑资产使用三方更新，模板自有协议覆盖前检查漂移，项目文档只初始化或保护，迁移只追加。

代价是增加版本锁、生成基线和接管流程；收益是跨电脑可重建、可审查、可恢复的初始化与升级。缺少可信基线时显式接管，不能以一次现有文件快照冒充历史模板内容。
