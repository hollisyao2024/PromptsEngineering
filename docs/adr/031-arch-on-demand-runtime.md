# ADR-031：轻量架构入口与固定来源缓存

状态：Accepted。日期：2026-09-10。关联：US-LAZYARCH-001~006。

原先 include architecture 和 init 会把全部模板源码复制进业务项目，按需安装依赖仍无法避免仓库冗余。选择在项目保存轻量入口、目录 metadata 与固定来源指针，完整生成源码保留在源仓库或容器缓存；按项目配置实例化模块。

未采用逐组件独立发布包：当前生成器共享配置校验、依赖闭包与版本清单，拆成网络包会增加版本组合复杂度。统一固定源码快照保留兼容性，后续可优化传输而不改变项目接口。未采用每次读取 main：会使普通架构命令隐式升级工具；版本升级仍由 template sync 显式触发。

代价：冷缓存需要网络或显式匹配的本地源。缓存摘要与版本必须校验；纯作业项目不启用架构。旧包由 baseline-aware remove 缩减，本地漂移阻断，未知文件保留；废弃 baseline 在新 lock 提交后精确清理。
