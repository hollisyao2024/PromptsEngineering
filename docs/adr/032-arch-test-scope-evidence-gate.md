# ADR-032：测试范围决策复用任务证据并在 QA 回执前校验

- 日期：2026-09-28
- 状态：Accepted
- 关联：US-CMDSURF-013

## 背景

模板已有按影响选测的文字规则，但未要求执行前形成可复核决策，`qa verify` 也不能发现证据缺失。阶段切换容易把全量测试当成默认动作。

## 决策

以共同约定定义全量测试的高门槛，由 TDD 执行前记录、QA 做语义复核。复用当前 task state 的 step evidence 保存结构化决策与结果；实际项目的 `qa verify` 在签发 SHA 回执前做字段、命令结果和 HEAD 绑定的结构校验。模板源保留既有 QA 路径，旧项目任务可补录同格式证据。

## 取舍与后果

复用 task evidence 不需要迁移状态或新增项目配置，实施和回滚范围小。结构检查不能证明影响分析充分或日志真实，因此 QA 仍须审查原始证据；模板也不会自动选择或运行测试。缺少记录的旧 mutation 任务需要在 QA 前补录，不能以历史任务身份豁免。
