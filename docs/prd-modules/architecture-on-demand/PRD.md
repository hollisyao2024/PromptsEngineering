# 架构按需获取 PRD

主纲：[PRD](../../PRD.md)。状态：已确认。日期：2026-09-10。用户授权：轻量架构入口、所选模块获取、已采用清单更新，修正息壤模板项目。

## 1. 目标与范围

实际项目只保留模型作业工具、轻量架构入口、适用标准与选择的生成代码。未选择的框架、模块模板、测试夹具和示例保留在息壤源或可重建缓存。项目维护者可以从小型单端逐步增加能力，完整蓝图不是强制配置。

范围：架构包获取、规划/初始化/更新/检查入口、固定来源缓存、3.3 全量架构包兼容缩减及文档。非范围：改变组件业务行为、卸载已采用业务模块、改变数据库/SDK 选型、更新其他实际项目、执行生产迁移或部署。

## 3. NFR 与用户体验

无图形界面。CLI 明确报告来源版本/缓存状态/计划/冲突及下一动作。轻量项目目录不包含 stacks、modules、registry 实现和模板测试；测试以文件清单验收，不把依赖未安装冒充源码按需获取。

来源固定为息壤官方身份及提交，工作流普通同步仍 required fetch。缓存不可作为最新版本依据；路径、符号链接、并发、中断、修改保护需要负例验证。缓存不含凭据，删除缓存后可重建。离线仅使用校验通过的已固定版本，不宣称已获取最新。

## 4. 依赖与里程碑

依赖现有文件所有权、baseline/lock、匿名获取协议和组件依赖闭包。按 PRD → ARCH → TASK → TDD → QA 交付。风险集中于旧包删除、来源漂移和入口失效，必须有真实消费者与旧版快照回归。开放问题：无。追溯见 [矩阵](../../data/traceability-matrix.md)。
