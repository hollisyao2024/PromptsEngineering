# 多端示例交互

页面顺序：导航（项目入口、主题切换）→ 页面标题与说明 → 筛选/新增/导出工具栏 → 任务表格 → 已选范围/分页。创建和编辑复用 FormDialog，字段为标题和状态；错误在字段和面板内呈现，失败保留输入。删除和批量删除复用确认组件，描述准确的 ID 数量；导出明确为当前筛选结果。所有控件使用 shadcn/Public DataTable。

320–767px：单列导航和可换行工具栏，表格只在容器内横向滚动；768px 以上：侧栏和内容区；面板不超视口，长表单内部滚动。触控主要操作目标至少 44px；表单标签、可访问名称、可见焦点、Esc 返回、关闭焦点恢复与键盘选项可用。色彩使用现有 background/foreground/muted/destructive/ring 等 Token，明暗主题复用同一组件树。

原型采用现有公共组件示例结构，新增 API 状态而不另外发明控件。自动化验证：读取与筛选排序；创建编辑删除与失败保留；窄屏导航、主题和重试。辅助技术、真人可用性和不同原生平台不能由 DOM 检查替代，证据注明验证范围。
