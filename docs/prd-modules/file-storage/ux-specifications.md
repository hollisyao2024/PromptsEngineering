# 文件上传交互

沿用 shadcn 语义色、间距、Button、Input、Progress 和反馈。文件输入封装在 UI primitive，业务组件不直接创建原生控件。窄屏纵向排列，宽屏呈现文件名、大小、进度和动作；触控动作至少 44px。

选择文件 → 大小/类型提示 → 请求会话 → 显示进度 → 服务端完成校验 → 成功回调。失败保留文件、重试重新申请会话；取消中止网络。身份不由控件推断，凭据不持久化。

键盘可达选择/上传/取消/重试，文件输入有标签，状态使用 aria-live，进度有可访问名称。测试空选择、上传中、取消、网络失败、服务端拒绝与成功。组件测试不代替真人可用性研究。
