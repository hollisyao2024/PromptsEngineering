# 构建与交付标准

应用 target、CPU、edition 和 environment 是独立维度，必须精确选择。开发启动、构建产物、迁移执行和环境部署使用不同命令；private 配置缺失时不回退 SaaS。平台不支持或真实命令未提供时明确失败。

runtime-assets 模块验证目标文件 SHA-256 和平台/架构匹配；plugins 模块校验 ID、路径、平台与声明权限，不把已安装第三方插件标记为签名可信。签名信任、安装权限和进程隔离由项目实现。

private profile 提供产物禁用地址扫描、发布目录切换和健康检查的参数化脚本。禁用地址由项目填写；空扫描目录或缺少策略会阻断。部署入口要求用户显式指定 release、current、health URL，初始化不会执行这些脚本。失败保留旧版本并回退符号链接，数据库迁移回滚须另行制定。
